# xmu助手 Android

原生 Android 端，和 Windows 端独立运行：本地登录、本地保存 Cookie、本地后台轮询、本地缓存课表成绩。

## 功能

- **首页**：账号登录（学号+密码）、监控开关、快速操作
- **签到情况 / 监控**：前台服务后台轮询，检测到签到后展示课程、类型、剩余时间和状态；支持数字签到和雷达签到自动处理
- **成绩**：读取百分制成绩，支持长图分享
- **课表**：从教务系统读取全学期排课，按周/日程两种视图展示；格子显示课程名、节次和当周教室，点击查看老师、完整周次和平行教学班详情
- **桌面小卡片（Widget）**：桌面「今日课程」小卡片，显示当天课程、时间、地点；策略页可开关、一键添加到桌面
- **课程课件**：选择学年学期课程，刷新并批量下载课件；无法直接下载的保存平台入口并显示原因
- **通知**：系统通知 + PushPlus 微信通知 + QQ 邮箱通知
- **教程**：内置各功能使用说明
- **策略**：轮询间隔、自动签到开关、桌面小卡片设置

## 本地与隐私

- 账号、Cookie、通知配置、课表缓存只保存在本机
- 桌面小卡片只读取非敏感摘要（课程名/时间/地点），不包含学号密码 Cookie
- 课表缓存带格式版本号，旧版本缓存自动失效并重新拉取

## 技术栈

- Kotlin + Jetpack Compose（Material 3）
- 前台服务 `RollcallMonitorService` 后台轮询
- `xmurollcall://rollcall/{event_id}` 深链接入口
- `AppWidgetProvider` 桌面小部件
- 加密存储（EncryptedSharedPreferences）保存账号与 Cookie
