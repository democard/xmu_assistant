## 复核与边界

- 在阻塞读取返回后及等到共享提交门后复核会话；已经通过提交门准入的单次同步 HTTP 调用允许完成，登出不撤回服务器已接收的操作。批次中的后续请求和旧界面回填被挡住；不跨网络调用持有 UI 会话锁。
- 本地课表修正和课程雷达地点仍按既有文档跨账号保留，未改变持久设置语义。
- 自动化未使用真实校园账号，未实际提交校园签到、邮件或通知；真实平台连通性、设备厂商后台行为与账号端到端结果仍需设备环境核验。
- 没有创建 Git commit、推送、上传 Release 或更新发布校验值。源码版本维持 1.8.5 / 46；下一次发布仍需递增版本、重新打包和校验。

## 复跑

仓库根目录运行：

```powershell
python -m pytest tests -q --tb=short
python -m ruff check xmu-rollcall-cli tests scripts
python -m compileall -q xmu-rollcall-cli tests scripts
cd android
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug --no-daemon --console=plain
```

Android 需要 JDK 17 和 Android SDK 35。依赖完整缓存时可加 `--offline`；如需强制重新执行全套而不复用任务结果，可加 `--rerun-tasks`。本机过期的 `local.properties` SDK 路径已校正，该文件仍由 Git 忽略。
