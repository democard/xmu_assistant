# 虾大助手 v1.7.4 · 双端兼容与稳定性更新

Windows 1.7.4；Android 1.7.4 / versionCode 31，支持 Android 8.0 及以上。

## 更新内容

- 改善双端记录详情查询的兼容性，修复跨日期、跨时区处理。
- 修复 Windows 后续查询空值或失败时复用旧缓存的问题。
- 统一公开介绍及界面文案，保留原有图像、接口、包名、数据目录和启动兼容标识。
- 补充模拟流程及边界回归。
