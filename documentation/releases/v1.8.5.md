## 已发布更新

- Android 首页新增一键签到，读取当前明细和本人状态，处理待提交的数字 / 雷达签到并跳过二维码签到。
- 改善签到同步栏、监控状态和分类卡片，补充签到码复制、雷达地点、缺勤标记与实时人数统计。
- 成绩、课表顶部信息固定；周课表左侧节次列保持可见；周次、安排编辑和课程选择使用可滚动弹窗；本地课表修正用于日历导出。
- 改善课程坐标与课件选择，统一自动签到开关；考试页支持下拉刷新和自定义提醒分钟数。
- Windows 改善课程 / 课件列表、雷达配置和教程；修复登录取消后的持久化回滚、下载进度刷新与跨平台路径打开。
