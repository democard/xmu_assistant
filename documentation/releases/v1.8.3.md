# 虾大助手 v1.8.3 · 恢复老版首页签到摘要

Android 1.8.3 / versionCode 44，支持 Android 8.0 及以上。Windows 保持 1.8.1。

[下载 Android APK](https://github.com/democard/xmu_assistant/releases/download/v1.8.3/xmu-assistant-release.apk) · [校验文件](https://github.com/democard/xmu_assistant/releases/download/v1.8.3/SHA256SUMS.txt) · [Windows 1.8.1](https://github.com/democard/xmu_assistant/releases/download/v1.8.1/xmu-assistant.exe)

## 更新内容

- **首页签到显示**：对照美化前的首页，在原有自动签到快捷开关区域内显示紧凑的“当前签到”摘要和“查看签到详情”入口，不新增独立模块，不重复显示签到详情卡片。
- **签到页闪退**：保留进行中与历史记录的分区标识修复，避免同一签到同时出现在两处时崩溃。
- 当前签到在前台自动刷新；手动刷新、数字码及雷达地点详情仍在签到页，原有“雷达签到坐标管理”按钮保留。
