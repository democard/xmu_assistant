# 虾大助手 v1.9.0 · 过渡版：下线自动签到、重做今日概览首页与畅课网页直达

Android 1.9.0 / `versionCode 48`，支持 Android 8.0（API 26）及以上；Windows 桌面端已正式声明废弃归档，本版起仅发布 Android 客户端安装包。

[Android APK](https://github.com/democard/xmu_assistant/releases/download/v1.9.0/xmu-assistant-release.apk) · [SHA-256 校验文件](https://github.com/democard/xmu_assistant/releases/download/v1.9.0/SHA256SUMS.txt)

## 背景与定位调整

由于学校方面已对相关策略与接口采取限制（拉闸），原**自动签到、一键签到、数字签到码抓取与课程雷达坐标定位**不再可用，已在源码、资源与界面层完整剥离。

客户端定位同步调整为**「课堂监听提醒 + 畅课直达 + 校园日常工具」**：在继续保留前台课堂监听提醒与教务日常工具的同时，提供应用内畅课签到网页直达，收到提醒后一键前往畅课完成签到。

## 更新内容

- **下线模块剥离与包体精简**：彻底删除雷达坐标页/几何解算、数字签到码探测及自动提交门控等死代码，并启用 `res/raw/keep.xml` 严格资源压缩（`tools:shrinkMode="strict"`），避免打包未实际引用的大图资源；Release APK 体积为 `4,047,974` 字节（约 `3.86 MB`）。
- **重做「今日概览」单屏首页**：重构首页信息排版，一屏呈现今日课程与下节教室、近期考试倒计时、课堂监听状态开关、进行中签到提示及常用功能入口（课表、成绩、课件、专业排名）。
- **新增应用内「畅课签到」网页（`TronclassWebViewPage`）**：支持从首页进行中签到卡片、签到详情页及「更多 → 畅课网页」进入；加载前预检会话状态并异步将本地加密存储的统一认证 Cookie 写入 WebView，支持免手动重复登录直达畅课页面。
- **保留全部教务与日常功能**：全学期周/日程课表与 `.ics` 日历导出、未来 14 天今日课程桌面小组件、成绩统计/模拟/长图分享/专业排名证明、课程课件搜索与断点续传、考试安排与闹钟提醒、快捷设置磁贴与系统主题跟随。
- **Windows 桌面端正式归档**：在根目录与 `xmu-rollcall-cli` 文档中声明废弃，本版不再随 Release 打包 Windows EXE。
