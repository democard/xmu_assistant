# 虾大助手 v1.8.4 · 双端稳定性与安全更新

Windows 1.8.4；Android 1.8.4 / versionCode 45，支持 Android 8.0 及以上。

[Windows EXE](https://github.com/democard/xmu_assistant/releases/download/v1.8.4/xmu-assistant.exe) · [Android APK](https://github.com/democard/xmu_assistant/releases/download/v1.8.4/xmu-assistant-release.apk) · [SHA-256 校验文件](https://github.com/democard/xmu_assistant/releases/download/v1.8.4/SHA256SUMS.txt)

## 更新内容

- **登录与任务恢复**：修复同账号重新登录后查询和自动任务卡住、旧任务结果覆盖新状态；任务准备或派发失败后能恢复操作。
- **避免重复提交**：桌面手动应答与自动任务共用提交门。手动可接管尚未提交的自动等待，暂停监控不影响手动应答。
- **课件下载**：续传绑定资源身份与强 ETag，避免同名不同课件或版本拼接；支持下载进度、取消和安全恢复，保留长文件名扩展名与编号。
- **账号与本地数据**：修复 Android 登录 Cookie 作用域、登出后旧任务写回历史缓存、雷达地点并发保存和失败回滚；改善桌面账号切换与配置目录并发探测。
- **邮件安全**：Android 强制 TLS 和服务器身份校验；双端仅在提交前安全切换备用端口，回执不明或成功后的退出异常不会重复发送。
- **维护流程**：加入双端 GitHub Actions、固定静态检查规则和 Windows 维护依赖约束，补充生产入口与故障恢复回归。

## 更新方式

- Windows：退出旧程序，用新 `xmu-assistant.exe` 替换原文件，保留本地配置。
- Android：沿用原包名与签名，可直接覆盖安装，不要先卸载。
- 旧版无归属信息的 `.part` 不自动续传，原文件保留，新下载使用编号名；同资源有强 ETag 时继续下载，没有可靠验证器则完整重下。
