## 已确定的复核原则

- 坐标库是持久地点设置，不等同于账号展示缓存。Python 原始模块明确约定“与账号无关（换号不清空）”；不能因 `clear()` 未被调用便在登出时销毁地点。旧账号课程选择器必须清理。
- Windows 公开版本 1.8.1、Android 公开版本 1.8.3 是独立版本线；未发布变更不应伪装成新发布版本。现有 Python `__version__` 与 Windows 版本一致，不能仅据此判断版本错误。
- 历史验证数保留为历史证据，本轮结果单独标明基线、工作区与实际命令。
- 已有公开 API 的兼容调用条件一并保留；新 UI 能力通过可选参数接入。

## Python 核心修复与独立发现

- **坐标保存失败产生内存幽灵配置**：新增、切换首选、删除、清空都先构建候选列表，原子写盘成功才替换内存。磁盘满或替换失败时旧内存与旧文件保持一致，自动应答不会使用 UI 已报失败的新增坐标。四种操作的旧源码失败断言已复现。
- **异常时间戳会阻断启动**：持久坐标中 `created_at_ms=1e999` 会抛 OverflowError；读取改为跳过坏记录，旧源码崩溃已复现。
- **密码恰以 `dpapi:` 开头**：配置保存明确按已知明文加密，不再因前缀跳过保护；包含合法 Base64 后缀的密码也可保存并恢复。公共 `protect()` 默认仍保留已加密输入的幂等契约。旧版已经误存的歧义字符串无法可靠判定归属，需重新输入后保存。
- **无当前账号的 Cookie 文件名**：显式 null 回落到默认 `1.json`，不再生成 `None.json`。保留现有加载配置与账号路径入口，不另建一套未解密读取逻辑。
- **下载进度与取消**：`download_courseware` 新增可选 keyword-only 回调，原三参数调用保持可用；按块报告文件已收字节、可知总长，续传包含已有字节，压缩流不拿传输长度充当解压文件总长。取消保留安全断点、清理临时片段并释放路径占位；重试可以续传。
- **长路径结论收窄**：本机 LongPathsEnabled=1，实际完成了 337 字符目标路径的下载。报告的 260 字符问题是旧策略环境风险，不是本机复现缺陷；本轮不静默截短用户目录或改文件命名规则。其他 Windows 策略环境未验证。
- **旧雷达 API**：生产桌面应答已注入坐标库；保留显式旧调用方和原有探测 API 的兼容条件，不以“强制注入”破坏现有公开入口。
- **禁系统代理设计**：保留现有有意行为，不在 bug 修复中改变用户联网路径。
